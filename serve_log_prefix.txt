KNOWN -> MATHS
  Max users at once  = min((KV space - shared) / (new input + output), max seqs)
                     = min((89328 - 400) / 200, 256) = 256 users
  Step time (full)   = (weights + users x KV/token x tokens) / memory speed
                     = (9.08 GB + 256 x 0.131 MB x 550) / 300 GB/s = 92 ms
  Prefill per request = 2 x prefill params x new input / real compute
                     = 2 x 6.98B x 100 / 46T = 30 ms of GPU time
  Decode per request = output x step time / users sharing it
                     = 100 x 92 ms / 256 = 36 ms of GPU time
  Max requests/s     = 1 / (prefill + decode per request)
                     = 1 / 0.066 s = 15.1 req/s   <- latency blows up after this
  E2E when alone     = prefill + output x (model size / memory speed)
                     = 0.03 s + 100 x 30 ms = 3.1 s
