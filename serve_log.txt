
meta-llama/Meta-Llama-3-8B-Instruct   input 500, output 100 tokens per request

KNOWN -> MATHS
  Max users at once  = KV space / tokens per user
                     = 29610 / 600 = 49 users
  Step time (full)   = (weights + users x KV/token x tokens) / memory speed
                     = (16.06 GB + 49 x 0.131 MB x 550) / 300 GB/s = 65 ms
  Prefill per request = 2 x prefill params x input / real compute
                     = 2 x 6.98B x 500 / 46T = 152 ms of GPU time
  Decode per request = output x step time / users sharing it
                     = 100 x 65 ms / 49 = 133 ms of GPU time
  Max requests/s     = 1 / (prefill + decode per request)
                     = 1 / 0.285 s = 3.5 req/s   <- latency blows up after this
  E2E when alone     = prefill + output x (model size / memory speed)
                     = 0.15 s + 100 x 54 ms = 5.5 s
